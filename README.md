# 🚚 LOGISTIQ – End-to-End Supply Chain Analytics

### Python-Based Supply Chain Performance & Predictive Analytics

> **Turning Supply Chain Data into Operational Intelligence.**

---

## 📌 About the Project

**LOGISTIQ – End-to-End Supply Chain Analytics** is a data analytics and machine learning project focused on analysing supply chain operations, evaluating delivery performance and identifying factors contributing to delivery delays.

Using **Python and its data analysis and machine learning libraries**, the project follows an end-to-end analytical workflow, covering data preparation, exploratory data analysis, feature engineering, root cause analysis and predictive modelling.

The project also explores how machine learning can be applied to historical supply chain data to predict potential delivery delays and support better operational decision-making.

## 🎯 Project Objectives

- Analyse overall supply chain performance.
- Evaluate delivery performance and late delivery patterns.
- Identify factors contributing to delivery delays.
- Perform root cause analysis to understand operational challenges.
- Prepare and transform data for analytical modelling.
- Develop a machine learning model for delivery delay prediction.
- Evaluate model performance and identify opportunities for improvement.

## 🔄 Project Workflow

### 1. Data Preparation

- Loading the supply chain dataset.
- Inspecting dataset structure and data types.
- Preparing data for further analysis.

### 2. Data Cleaning & Preprocessing

- Handling missing and inconsistent values.
- Preparing relevant columns for analysis.
- Converting and organising data types.
- Removing unwanted or duplicate records where required.

### 3. Exploratory Data Analysis (EDA)

- Exploring supply chain data distributions.
- Analysing delivery performance.
- Identifying patterns and relationships.
- Visualising important operational trends.

### 4. Root Cause Analysis

- Investigating factors associated with late deliveries.
- Examining operational patterns affecting delivery performance.
- Identifying potential sources of supply chain inefficiencies.

### 5. Feature Engineering

- Preparing relevant features for predictive modelling.
- Transforming variables into suitable formats.
- Organising model-ready data.

### 6. Machine Learning – Delivery Delay Prediction

- Developing a Random Forest classification model.
- Training the model using prepared supply chain data.
- Predicting potential delivery delays.
- Evaluating model performance using classification metrics.

### 7. Model Evaluation & Insights

- Reviewing prediction accuracy.
- Assessing model performance.
- Interpreting analytical findings.
- Identifying potential opportunities to improve delivery operations.
